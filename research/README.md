# Research behind the game

Working notes from October 2026, kept so every curriculum claim in the game can be
traced to its source. Each claim carries a confidence tag: **confirmed** (a primary
document, or two independent sources, agree), **partly** (one secondary source, or a
detail differs) or **unverified**. Each file opens with its method and limits.

| file | what it covers |
|---|---|
| `COACH-MATH.md` | how class solves it in McGraw Hill Reveal Math, kindergarten to grade 5: strategies, when each starts, the words class uses and avoids. The basis for SHOW ME HOW in math |
| `COACH-ELA.md` | Amplify CKLA phonics and comprehension routines, the sound sequence and Tricky Words. The basis for SHOW ME HOW in reading and for the Reading Road |
| `grade1-ela.md`, `grade1-math.md`, `grade1-science-ss-health.md` | what 1st grade covers at AACPS and in Maryland's standards, for the 1st grade packs |

The game's summary of all this, including what could not be verified, is
[CURRICULUM-NOTES.md](../CURRICULUM-NOTES.md). These notes were written with an AI
assistant from publicly available sources; several official websites could not be
opened directly, as each file says.
